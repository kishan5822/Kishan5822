### 📄 AI-Powered Document Chatbot (RAG System)
> End-to-end RAG pipeline for natural language querying across multi-format documents

- Full pipeline: ingestion → chunking → embedding → vector indexing (ChromaDB/FAISS) → retrieval → synthesis
- Quantized **LLaMA 7B (8-bit)** via llama.cpp for optimized local inference
- Supports PDF, DOCX, PPTX, Excel and web URLs
- Structured evaluation framework — **85%+ accuracy** across diverse document types
