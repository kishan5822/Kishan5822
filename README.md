## Featured Projects

### 📄 DocMind — Full-Stack RAG Application
> Multi-user, multi-format RAG web app deployed live on Vercel

- Full-stack build (**Next.js + FastAPI**) supporting 10+ document formats — PDF (with OCR), DOCX, PPTX, XLSX, CSV, images
- Auto-ingestion with **per-session isolated vector stores** for secure concurrent multi-user usage
- Hybrid retrieval fusing **ChromaDB vector search + BM25 keyword search + FlashRank reranking**
- Local **BGE embeddings** on CPU; **Groq API** used only for final grounded, document-cited answer synthesis

### 📊 RAG Evaluation Dashboard (RAGEval)
> Production-deployed LLM evaluation platform

- Built with **FastAPI + RAGAS + DeepEval**, automating RAG pipeline scoring across **8 metrics** — faithfulness, hallucination, context precision, answer relevance and more
- Multi-provider judge LLM support — **Groq, Gemini, OpenRouter**
- Interactive dashboard with per-sample breakdowns, radar charts and failure categorization badges
- REST API for live RAG integration with CSV/JSON export; deployed on **Railway via Docker**
